# Currency Exchange API

API для просмотра курсов валют, конвертации и построения графиков. Источник данных: ЦБ РФ.

## Возможности

- 📊 Просмотр актуальных курсов валют ЦБ РФ
- 💱 Конвертация между любыми валютами (через рубль)
- 📈 Исторические данные и графики
- 🔔 Система уведомлений о достижении курсом заданного значения
- 🔐 Аутентификация через JWT

## Быстрый старт

### Требования

- Go 1.22+
- Docker & Docker Compose (для запуска с БД)
- PostgreSQL 15+ (для локальной разработки без Docker)
