API docs by Redocly

Currency Exchange API (1.0.0)

Download OpenAPI specification:

API для просмотра курсов валют, конвертации и построения графиков. Источник данных: ЦБ РФ. Все кросс-курсы рассчитываются автоматически через рубль.

История курса для валютной пары

Возвращает исторические данные для построения графика. Поддерживает прямые пары (USD/RUB) и кросс-курсы (EUR/USD).

path Parameters
pair
required
string
Example: EUR_USD

Валютная пара в формате BASE_QUOTE

query Parameters
period
string
Default: "1m"
Enum: "1d" "1w" "1m" "3m"

Масштаб времени для графика

fill_gaps
boolean
Default: false

Заполнять пропуски (выходные/праздники) значением предыдущего дня

Responses

Local development

http://localhost:8080/rates/{pair}

Response samples

  • 400
  • 404
  • 500

  • "period": "string",
  • "data": [
    • {
      • "date": "2019-08-24",
      • "rate": 0.1
      }
    ]
}
